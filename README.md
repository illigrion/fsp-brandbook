# ФСП — финальная сборка для сервера

Загружайте `dist/` в корень сайта.

## Структура

```
dist/
├── index.html              ← Брендбук (главная страница)
├── design.html             ← Основной сайт ФСП
├── land.html               ← Список рекламных лендингов
├── oiva.html               ← Лендинг FP-7 «Oiva»
├── max.html                ← Лендинг FP-4 «Max»
├── landing.css             ← Стили лендингов
├── fonts/                  ← Montserrat 300–900 + italic
└── assets/                 ← Фото, рендеры, лого
```

## URL-схема

| Адрес | Назначение |
|---|---|
| `/` или `/index.html` | Брендбук / дизайн-система |
| `/design.html` | Основной сайт ФСП |
| `/land.html` | Витрина рекламных лендингов |
| `/oiva.html`, `/max.html` | Лендинги под рекламу конкретных моделей |

Все пути относительные. Можно класть и в корень `/`, и в подпапку — работать будет одинаково. Никаких CDN-загрузок и inline-eval — CSP-friendly.

## Что подключить дальше

- **Аналитика** — счётчик Yandex Metrika / GA вставьте в `<head>` каждого файла
- **Формы** — на лендингах `<form onsubmit="...">` сейчас показывает «спасибо» локально. Подключите отправку в CRM/AmoCRM/Bitrix24

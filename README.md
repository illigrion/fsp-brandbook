# ФСП · FINSTROYPANEL — Design System

**Бренд:** ФСП («ФинСтройПанель») — производитель и застройщик энергоэффективных малоэтажных домов из **сборного трёхслойного железобетона** (финская монолитная технология).

**Продукт:** проектирование, изготовление панелей на заводе, монтаж под ключ. Дом 180 м² → коробка за ~14 дней, заезд через 45–47 дней. В ипотеку. Регионы: Москва, СПб, Екатеринбург, Казань, Новосибирск + по всей России.

**Тон:** инженерный, документальный, технически грамотный. Цифры, ГОСТы, сроки — не «мечта о доме».

## CONTENT FUNDAMENTALS

### Tone of voice — «инженер, а не маркетолог»

ФСП говорит языком документации, а не рекламы. Это **спокойный, конкретный, технически грамотный** голос: цифры, ГОСТы, материалы, сроки. Никакой «мечты о доме», никаких «премиальных решений», никаких эмодзи.

### Правила копирайта (из секции 14 · Tone of voice)

| Делаем так | Не делаем |
| --- | --- |
| «Дом 180 м² за 47 дней монтажа» | «Дом вашей мечты — быстро и легко» |
| «120 мм утеплителя в каждой панели» | «Самые тёплые дома в России» |
| «Несущий слой — бетон М400, утеплитель — PIR 120 мм» | «Используем только премиальные материалы» |
| «Соответствует ГОСТ 31310-2015» | «Высочайшее качество, проверенное годами» |
| «Заказать расчёт панелей за 3 дня» | «Превратите вашу мечту в реальность!» |
| «Скачать каталог проектов · PDF, 4.2 МБ» | «Узнать больше о нашей компании» |
| «Сегодня залили 1 240 м² панелей. Партия едет в Истру.» | «Поздравляем всех с понедельником! 😊» |

### Конкретика

- **Обращение:** «вы» — нейтральное, никогда «ты». В отчётных кейсах — третье лицо («сегодня залили…», «партия едет…»).
- **Местоимения:** «мы» (компания) — допустимо, но без хвастовства. Лучше показать действие, чем рассказать о себе.
- **Числа:** всегда конкретные, с единицами и стандартами. `180 м²`, `120 мм`, `М400`, `ГОСТ 31310`. Tabular-nums.
- **Casing:** Sentence case в заголовках; **UPPERCASE** только в шильдиках/метках/eyebrow (tracking `0.08–0.2em`).
- **Пунктуация:** неразрывные пробелы перед единицами (`180&nbsp;м²`). Тире `—`, не дефис. Точка в конце заголовков-утверждений («Три слоя — одна стена.»).
- **Эмодзи:** **запрещены.** Эмодзи в коммуникациях ФСП не используются.
- **Восклицательные знаки:** только в предупреждениях по технике безопасности. В рекламе/маркетинге — нет.
- **Английский:** допустимы английские названия серий (FSP, KP-3) и техдокументы. Логотип существует в двух алфавитах (FIN/STROY/PANEL и ФИН/СТРОЙ/ПАНЕЛЬ).

### Vibe в одной фразе

> «Сегодня залили 1 240 м² панелей. Партия едет в Истру.»  
> — это и есть голос ФСП.

## VISUAL FOUNDATIONS

### Палитра

Три рабочих цвета, четыре опорных нейтрали, один сигнальный.

- **Primary · `--navy` #2D4F91** — флагман, идентификация, акценты, CTA. Pantone 287 C.
- **Primary · `--graphite` #2A2A2D** — текст, тёмные поверхности, футер.
- **Primary · `--paper` #F7F6F2** — основной фон. **Тёплый off-white**, не белый.
- **Accent · `--red` #C0071A** — **только сигнал**: спецодежда, важные предупреждения, акценты инфографики, метка «срочно». Никогда не CTA.
- **Neutrals:** `--cement` #C9C8C3 (хайрлайны), `--concrete` #ECECEA (фоны), `--paper-2` #FAFAF7 (альт. фон секций).
- **Шкала:** см. `colors_and_type.css`. Navy → 5 ступеней (50/100/200/700/900). Graphite → 4 ступени.

**Правило пропорций 60/30/8/2:** 60 % бумажный/бетонный фон · 30 % графит · 8 % синий · 2 % красный. На любом макете.

### Типографика

- **Единственный шрифт: Montserrat.** Веса 300 / 400 / 500 / 600 / 700 / 800 / 900 + italic. Закрывает RU и EN.
- **Заголовки:** ExtraBold 800 / Black 900, `letter-spacing: -0.02em ÷ -0.04em` (отрицательный трекинг — обязательное правило для крупного кегля).
- **Body:** Regular 400, `line-height: 1.55–1.65`, размер 16 px на экране, 9 pt в печати (минимум).
- **Eyebrow / метки / шильдики:** Medium-SemiBold 500/600, **UPPERCASE**, `letter-spacing: 0.08em ÷ 0.20em`. Используется в `kicker`, `label`, `tag`, `note`.
- **Цифры:** Всегда `tabular-nums` (`.mono` / `.t-tnum`). Стат-блоки и инфографика — Black 900 c очень негативным трекингом (−0.03 ÷ −0.04em).
- **Никаких других шрифтов.** Никаких serif, никаких script. Mono — Montserrat tabular.

### Пространство, сетка, ритм

- **Базовый модуль: 8 px.** Все отступы кратны: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128.
- **Сетка:** 12 колонок, желоб 24 px, поля `clamp(24px, 5vw, 80px)` (gutter).
- **Брейкпойнты:** XS ≤480 / SM 481–768 / MD 769–1024 / LG 1025–1440 / XL ≥1441.

### Геометрия и формы

- **Углы: 0 px.** Всё квадратное — кнопки, карточки, поля, бейджи, фото-маски. **Скругления запрещены** (это инженерный бренд про панели — углы прямые).
- **Бордеры:** `1px solid var(--cement)` — стандартный хайрлайн. На графите → `1px solid #1a1a1c`.
- **Тени:** в статике их **нет**. Единственное исключение — `0 16px 32px -16px rgba(20,30,50,0.15)` на hover карточки-проекта. Никаких drop-shadow на типографике или лого.

### Фоны

- **Канвас:** `--paper` #F7F6F2.
- **Альт. секции:** `--paper-2` #FAFAF7 — едва заметно светлее, разделение разделов без линеек.
- **Тёмные блоки:** `--graphite` #2A2A2D (футер, CTA-полосы, технологические визуализации).
- **Фирменный синий блок:** `--navy` для hero-акцентов и инфографики.
- **Никаких градиентов.** Кроме обложки (`paper` → `paper-2` снизу, едва различимо) и сигнальной строки `cover-stripes`. Bluish-purple gradients **запрещены явно** (есть в don'ts).
- **Никаких текстур, паттернов-картинок.** Паттерн — только из «III»-брусков (см. секция 07 Pattern).
- **Прозрачность / blur:** только на nav-баре сайта (`backdrop-filter: blur(8px) saturate(1.05)` поверх `rgba(247,246,242,0.92)`). И на photo-overlay (`rgba(20,25,35,0.78)` + `blur(10px)`).

### Карточки

```
background: #FFFFFF (или --paper для встроенных)
border:     1px solid var(--cement)
border-radius: 0
padding:    24px ÷ 32px
shadow:     none (hover: --shadow-hover)
```

Внутри карточки:
- `.num` — eyebrow UPPER 11px, tracking 0.18em, цвет `--graphite-500`
- `h4` — 17–22 px, ExtraBold 800, tight tracking
- `p` — 13–14 px, цвет `--graphite-500`
- (опц.) числовая статистика — Black 900, 56 px, navy или red

### Hover / pressed states

- **Кнопка primary:** `background: var(--navy)` → `var(--navy-deep)` (на 7% темнее).
- **Кнопка secondary:** transparent → `var(--navy-50)`.
- **Кнопка ghost:** transparent → `var(--graphite)` (инверсия).
- **Карточка проекта:** `transform: translateY(-3px)` + `shadow-hover` + увеличение `img` внутри `.ph` до 1.04 (slow ease 500ms).
- **Active/pressed на кнопке:** `transform: translateY(1px)`. Без смены цвета.
- **Ссылка в нав-меню:** color → `var(--navy)`.
- **Фокус полей:** `border-color: var(--navy)`. Никакого outline-glow.

### Анимация

- **Длительность:** 120–250 ms. По умолчанию 150 ms.
- **Easing:** `ease` (по умолчанию), `cubic-bezier(.2,.7,.2,1)` (карточки), `ease-out` (входы).
- **Бесконечные анимации:** нет. Никакого «дыхания», свечения.
- **Свойства:** `color`, `background`, `border-color`, `transform: translateY()`, `box-shadow`. Никаких `rotate` или `scale` (кроме субтильного 1→1.04 на фото).
- **Прокрутка:** sticky nav. Никаких parallax.

### Иконография

См. секцию ICONOGRAPHY ниже.

### Логотип: «III» — три бруска, растущие по ширине и насыщенности

- **Знак** — три вертикальных бруска, **одинаковой высоты**, но **разной ширины и цвета**:
  - **Бар 1** (слева): самый узкий, светлый navy — **#A8B6D5** (`--bar-light` / `--navy-200`).
  - **Бар 2** (середина): средний по ширине, средний синий — **#5979B5** (`--bar-mid`).
  - **Бар 3** (справа): самый широкий, тёмный navy — **#2D4F91** (`--bar-dark` / `--navy`).
- **Пропорции ширин: 2 : 3 : 4.** Зазор между барами = 1 модуль (равен ширине самого узкого бара).
- **Это критическое правило бренда.** Если бары одинаковой ширины — это не логотип ФСП. Если цвета одинаковые — это не логотип ФСП.
- **На тёмных фонах** (graphite, navy, red) знак переходит в белые тона с градацией прозрачности: 0.55 / 0.78 / 1.0.
- **Минимальный размер:** 24 px на экране, 8 мм в печати.
- **Угол наклона:** 0°. Наклон запрещён.
- **Wordmark:** три строки `FIN / STROY / PANEL` (или `ФИН / СТРОЙ / ПАНЕЛЬ`), Montserrat ExtraBold 800, выровнен по высоте знака.

### Imagery — фотография

- **Документально.** Реальные площадки, бригады в спецодежде, монтаж панели, готовый дом, портреты партнёров. Никаких рендеров вместо фото, никаких рукопожатий из стока.
- **Свет:** естественный. Цвет: **холодноватый**, баланс белого до +200K в тёплый.
- **Контраст:** средний. Тени глубокие, света без выбивания. Никакого HDR, оранжево-бирюзы, наклонов.
- **Без фильтров.** Без эмоций «успеха». Без виньетирования.

### Применения / носители

Спецодежда (полевая красная, кэжуал тёмно-синяя), брендированный автотранспорт, фирменный бланк A4, визитка 85×55, баннер 3×2 м на стройплощадке, стикер на каску, посты 1080×1080 в соцсетях. См. секцию 12.

## ICONOGRAPHY

### Стиль: «линейная, чертёжная, на модуле 24»

Иконки ФСП — **инженерный чертёж в миниатюре**, не пиктограммы из дизайн-системы общего назначения.

- **Сетка:** 24 × 24 px.
- **Stroke:** `stroke-width: 1.5px`.
- **Углы линий:** `stroke-linecap: square; stroke-linejoin: miter`. **Без скруглений**, без `round`-stroke.
- **Заливка:** `fill: none`. Только обводка.
- **Цвет по умолчанию:** `currentColor` (наследует `--graphite`). На тёмных фонах — `#fff`.
- **Декор:** запрещён. Никаких градиентов, теней, двойных обводок, объёма.

### Реализация

Иконки **встроены инлайн как SVG** в HTML (см. `reference/FSP Design System.html`, секция 08). Иконочного шрифта или sprite-файла **нет**. Это сознательное решение: набор маленький (~12 базовых иконок), все рисуются по чертёжному модулю руками.

Базовый набор брендбука (символ → значение):
`Панель` · `Дом` · `Объект` · `Готово ✓` · `Срок ⌚` · `Гарантия` · `Завод` · `Регионы` · `Стандарт` · `Документ` · `Этаж` · `Эффективность ↗`.

### Если нужна иконка, которой нет

1. Сначала **попробуй нарисовать её под брендовый стиль:** 24×24, stroke 1.5, без скруглений, square caps, miter joins. Скопируй паттерн из существующих в `reference/FSP Design System.html` (секция `#icons`).
2. **CDN fallback:** если стиль точно совпадает — **Lucide** (`https://unpkg.com/lucide-static/icons/...`). Lucide использует round-caps по умолчанию — **поменяй на `square`** в готовом SVG, иначе стиль ломается.
3. Не подключай Material Icons, Heroicons (fill-стиль), FontAwesome — все они слишком декоративны или круглы.

### Эмодзи · Unicode-символы

- **Эмодзи: запрещены** (правило бренда — см. секция 14).
- **Unicode-стрелки** (`→ ← ↗`) — допустимы только в технических подписях, очень осторожно. Лучше — линейная стрелка из HTML/CSS (см. `.btn .arrow`).
- **Маркеры списков:** dot 6×6 `background: currentColor`. **Никаких bullet-знаков `•`, `–`, `●`.**

### Бренд-знак как графический элемент

«III» (три бруска) — это **универсальный графический модуль**, не просто логотип. Из него собираются:
- разделители («лента-эквалайзер», секция 07.2),
- большие фоны («уходящие панели», 07.1),
- диагональные ленты на обложках (07.3),
- баннерные стрипы в футере сайта.

При использовании на цвете — три бруска инвертируются в белый с градацией прозрачности 0.55 / 0.78 / 1.0 (см. `colors_and_type.css` или `__brand-bars` override в брендбуке).

## How to use

1. **Production code:** подключи `colors_and_type.css`, копируй паттерны из `reference/FSP Design System.html` и `reference/FSP Website.html`. Все компоненты уже есть в виде HTML/CSS.
2. **Слайды / промо / mock-up:** копируй ассеты из `assets/`, придерживайся правила 60/30/8/2 и геометрии «III». Без скруглений, без эмодзи, без градиентов.
3. **Сомневаешься в тоне:** перечитай таблицу в `CONTENT FUNDAMENTALS` выше. Если фраза начинается с «Превратите вашу…» — стоп.
